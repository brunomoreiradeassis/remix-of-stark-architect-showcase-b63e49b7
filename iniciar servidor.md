# Iniciar o servidor

1. Instale as dependências:

```bash
pnpm install
```

2. Inicie o servidor de desenvolvimento:

```bash
node scripts/command-server.cjs
```
Depois:

```bash
pnpm run dev
```

3. Acesse a aplicação pelo endereço exibido no terminal (ex.: http://localhost:8080/). Se a porta estiver ocupada, o Vite escolherá outra automaticamente.
